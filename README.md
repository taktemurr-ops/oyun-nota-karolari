# Nota Karoları · Note Tiles

İnen karolara vaktinde dokun, klasik ezgileri kendin çal

Karo çizgiye gelince şeridine dokun; uzun karoları basılı tut. Boş şeride dokunmak ya da karo kaçırmak can götürür. Pratik modunda tempo yavaşlar.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Müzik ve Ritim merkez uygulamasının oyunu; ortak motor: [muzik-motoru](https://github.com/taktemurr-ops/muzik-motoru).
